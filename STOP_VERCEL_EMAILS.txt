STOP VERCEL FAILURE EMAILS
==========================

Your site now deploys with Cloudflare (GitHub Actions). Vercel is still connected to GitHub,
so every push tries to build on Vercel too -> failed build emails.

FIX (pick one):

A) Vercel dashboard -> each project (faith-driven-life, faith-driven-life-hlzj) ->
   Settings -> Git -> DISCONNECT repository faith-driven-life

B) GitHub -> repo Settings -> Integrations / GitHub Apps -> Vercel -> remove this repo

C) vercel.com/account/notifications -> turn off failed deploy emails

Then pushes only run Cloudflare deploy in Actions, not Vercel.
